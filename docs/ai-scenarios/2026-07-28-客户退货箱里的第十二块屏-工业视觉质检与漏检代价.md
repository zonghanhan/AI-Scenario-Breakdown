# 2. 业务场景故事

## 《客户退货箱里的第十二块屏》

### 第一章：良率 99.2%，客户却在退整箱货

周三上午 9:40，消费电子代工企业「锐视」的质量总监老周冲进会议室，把一摞退货照片摔在桌上：「客户说这批 2,000 块中尺寸手机屏，开箱不良率飙到 0.6%。我们自己的出厂全检报告写的是 99.2% 良率。差出来的 0.6%，够他们停我们两条线。」

产线视觉质检负责人林薇调出昨晚的检测日志。每一块屏在包装前都经过三道工位：外观面阵相机拍正面、侧面线扫看边框、背光工位查漏光与坏点。算法给出 OK / NG（不良）判定，NG 的进复判台，OK 的直接装箱。

「模型没挂，相机没脏，节拍也没掉。」林薇指着大屏，「昨晚 11,847 块屏，自动 NG 312 块，人工复判放行 41 块，最终出货 11,535 块。系统记录一切正常。」

老周指着退货样张里一道极细的斜向亮线：「客户圈出来的划痕，长度不到 0.4 毫米，在特定角度反光下才看得见。我们的系统昨晚把它判成了 OK。」

产品经理陈航刚接手这个视觉质检项目两个月。他第一反应是：「是不是阈值设太松了？把灵敏度调高，多拦一点不就完了？」

林薇摇头：「上周你把划痕类阈值调高 8%，漏检是少了，但误拦从 1.9% 涨到 4.7%。一条线一小时 1,200 块，误拦多 34 块，复判台三个人根本接不住，产线被迫降速，老板已经骂过一轮了。」

**悬念**：漏检和误拦像跷跷板——压一头，另一头就翘起来。陈航盯着那张退货照片，意识到问题根本不是「模型准不准」一句话能说完的。

---

### 第二章：产线上那 0.8 秒，到底在判什么

下午，陈航跟着林薇下到三号包装线。一块屏从传送带进入检测工位，机械臂定位、光源亮起、四台工业相机同步曝光，全程 0.8 秒。屏离开工位前，屏幕上已经跳出结果：绿色 OK。

「你以为 AI 在看一整块屏。」林薇打开后台，「实际上系统在跑一条流水线：图像采集 → 预处理 → 缺陷定位 → 分类 → 尺寸/位置测量 → 综合裁决。」

图像预处理先校正透视、压反光、做平场补偿——同一道划痕，在旧光源下是暗线，换一批 LED 模组后可能变成亮线。缺陷检测模型（通常基于深度学习的目标检测或分割）会在图上框出疑似区域：划痕、污点、崩边、气泡、异物。每个框带类别和置信度。随后规则层量长度、面积、与边框距离、是否落在「外观 A 区」（用户一定看得到的面）还是「结构 B 区」（装机后看不见）。

昨晚那块问题屏，模型其实在右下角框出了一个 0.31 毫米长的疑似划痕，置信度 0.62。规则写的是：A 区划痕长度 ≥ 0.35 毫米且置信度 ≥ 0.70 才判 NG。它卡在了阈值下面，综合裁决给了 OK。

陈航问：「0.62 不算低啊，为什么不能进复判？」

林薇调出过去两周数据：「如果把所有 0.55–0.70 置信度的疑似缺陷都送人，每天要多 600 多块进复判台，人均判一块要 25 秒，产线节拍直接从 0.8 秒拉到 1.4 秒。工厂算过账：复判台每加一个人，一年人力 28 万；停线一分钟，折合 4,600 元。漏检贵，误拦也贵。」

**这里 AI 的决策权限很清晰**：高于硬阈值的自动 NG；低于放行阈值的自动 OK；中间地带叫「灰区」，可以进复判、可以降速抽检、也可以按客户批次风险动态调整——但绝不能假装不存在。

---

### 第三章：人工复判台不是「模型不行就全上人」

复判间里，质检员吴姐戴着遮光罩，面前是原图、增强图、热力图和 3D 高度图四联屏。她手里这块屏，是算法判 NG、她准备放行的——边框内侧 0.2 毫米长的点状污迹，在最终装机后会被支架挡住。

「我能放行，不是因为眼睛比机器好。」吴姐点了几下，「是因为我知道这块屏的装机构型。机器只知道『这里有污点』，不知道『装进去后用户看不看得到』。」

她的每次操作都进系统：确认 NG、改判 OK、标记「可忽略缺陷」并选择理由码。这些记录不会消失，而是回流到每周的缺陷评审会：哪些「可忽略」其实被客户投诉了，哪些规则该收紧，哪些该给模型补样本。

陈航原先的设计稿里，复判台只是一个「大按钮：通过/驳回」。林薇让他实地坐了一小时，他才发现真正耗时的是：在六种增强视图间切换、对照工艺标准 PDF、确认缺陷是否在客户合同附件 3 的允收范围内、以及处理「这块屏和上一块几乎一样，为什么一个 NG 一个 OK」的一致性争议。

团队后来给复判台加了三件事：

1. **缺陷证据包**：自动把框选区域放大、做差分、叠加工单上的允收标准示意图；
2. **相似案例检索**：从历史 12 万块屏里找同位置、同类别、同客户裁决结果；
3. **双人复核入口**：对「改判 OK 的 NG」和高价值客户批次，要求第二人确认。

人工不是模型的替补，而是**把业务语境补进裁决**的最后一环。但人工也贵、会疲劳、标准会飘——所以系统还要统计复判员之间的一致性，定期做金标样块考核。

---

### 第四章：换了一种膜，同一套模型一夜失灵

问题还没查完，夜班班长打来电话：「新导入的防眩光膜批次一上线，误拦率飙到 11%。线要停了。」

陈航以为是相机脏了。林薇远程一看就知道：「不是脏了，是域偏移（domain shift，也就是新物料表面纹理变了，旧模型没见过）。新膜雾面颗粒更细，侧光下会出现成片弱纹理，模型把纹理当划痕，一晚上报了 900 多个假缺陷。」

团队启动应急预案：

- **短期**：切换「新膜专用」降级策略——对该批次临时提高 NG 阈值，同时把灰区比例从 3% 提到 8%，加开临时复判工位；
- **中期**：采集新膜 200 块金样，含已知真缺陷和易混淆伪缺陷，48 小时内微调模型；
- **长期**：把「新物料导入」写进变更流程：任何膜材、盖板、油墨、工装夹具变更，必须走视觉质检回归验证，不能等客户退货才发现。

这次没有「一键回滚到上周模型」那么简单。上周模型在新膜上漏检会上升，新模型在旧膜上又要重新验。最终他们维护**按物料批次路由的模型版本表**：线体 PLC（可编程逻辑控制器，管产线设备与节拍）读到当前 BOM 批次号，视觉系统加载对应模型和阈值包。

陈航在变更单上补了一行产品需求：「新物料试产阶段，自动通过率不得高于历史均值 5 个百分点，否则触发预警。」——用流程防止「为了赶产量悄悄放宽标准」。

---

### 第五章：客户退货箱里的第十二块屏，把账算清了

一周后，根因基本对齐：问题批次用的是某款新膜，灰区里的低置信划痕被旧阈值放行；客户产线抽检角度更刁，0.3 毫米以上的 A 区划痕一律拒收。第十二块被圈出来的屏，成了整批质量争议的样本锚点。

老周要的不只是「再训练一个模型」，而是一张**质量经济学账表**：

| 项目 | 旧策略 | 新策略（灰区分层 + 批次模型） |
|---|---|---|
| 漏检率（A 区划痕） | 0.18% | 0.05% |
| 误拦率 | 1.9% | 2.8% |
| 复判人力 | 3 人/班 | 4 人/班 |
| 单块检测耗时 | 0.8 秒 | 0.9 秒 |
| 月度客户质量索赔 | ¥ 186 万（含本次） | 预估 ¥ 40 万 |
| 产线有效产出 | 基准 | -3.2% |

「多雇一个人、慢一点，比丢一个大客户便宜。」老周说，「但你要是敢把误拦率拉到 8% 还说『零漏检』，我会先停你的项目。」

陈航把产品目标从「提高模型准确率」改成三条可运营指标：

1. **A 区致命缺陷漏检率** ≤ 客户合同上限（这是红线）；
2. **综合误拦率** ≤ 产线可消化上限（由复判产能反推）；
3. **单块质检综合成本** = 算力 + 设备折旧 + 复判人工 + 索赔期望（这是老板看的）。

上线新策略后，灰区样本 100% 进复判，其中 12% 被确认真 NG，88% 放行。那 12% 就是旧策略可能漏掉的「第十二块屏」。客户下一批抽检不良率回到 0.08%。

---

### 第六章：复盘会上，算法同学说的 98.7% 被当场拆开

月度复盘，算法工程师汇报：「划痕类检测 mAP 98.7%。」

林薇照例追问三个业务问题：

1. **在客户定义的 A 区、0.3 毫米以上划痕上，漏检率是多少？** —— 不能拿全图、全尺寸混合指标糊弄。
2. **自动 OK 的样本里，下游客户投诉率是多少？** —— 比实验室指标更接近真实漏检。
3. **误拦样本里，多少是伪缺陷（膜纹、反光）？** —— 决定该补数据还是该改光学方案。

他们还建立**缺陷金字塔**监控：ppm（百万分之不良）按客户、批次、工位、班次、物料供应商分层。某供应商膜材一波动，ppm 曲线比人先抬头。

陈航终于能说清楚这个系统是什么：不是「装几个摄像头 + 调个模型」，而是**把光学、算法、产线节拍、工艺标准、人工复判和客户合同绑在一起的工业视觉质检系统**。AI 负责在高节拍下不漏看；规则负责把客户标准翻译成机器阈值；人负责灰区和语境；变更管理负责新物料不把旧模型悄悄变成坑。

# 3. 系统正解

工业视觉质检系统的核心数据流是：**产线触发采集 → 光源与相机同步曝光 → 图像预处理与配准 → 缺陷检测/分割模型 → 几何测量与工艺规则引擎 → OK/NG/灰区裁决 → 复判台与 MES（制造执行系统）回写 → 缺陷样本与指标回流训练**。故事第一、二章对应采集链路与检测裁决；第三章是复判台与人机协作；第四章的换膜事故对应模型版本管理与物料变更回归；第五章的退货箱对应漏检代价与阈值经济性；第六章对应分层指标与持续监控。对 AI 产品岗来说：

- **写需求文档时**：不要只写「检测划痕」，要写明缺陷字典、分区标准、尺寸阈值、节拍约束、NG 后流向和与客户合同的映射关系。
- **做方案评审时**：问清漏检与误拦的业务上限各是多少、灰区如何处理、新物料导入谁签字、模型版本如何与 BOM 批次绑定。
- **设计指标时**：按缺陷等级和客户区域拆「致命漏检率」「可接受误拦率」「复判一致率」「单件质检成本」，拒绝单一准确率。
- **跨团队沟通时**：与工艺确认允收标准是否可量化；与设备确认光源/相机变更流程；与算法确认伪缺陷样本占比；与客户成功确认索赔条款如何反哺阈值。

# 4. 类比锚定

可以把工业视觉质检类比成**高速收费站 ETC + 人工抽检通道**。

车辆（产品）以固定速度通过门架（工位），系统先自动判「正常通行 / 拦截」，可疑车辆导入人工岗亭复核；收费标准和车型规则（客户合同）决定什么算超限；换了一种新车牌样式（新物料）可能导致识别器一时认不准——需要更新规则或模型，而不是硬扛旧配置。

| 收费站 ETC 与抽检（旧经验） | 工业视觉质检系统（新系统） | 对应关系为什么成立 |
|---|---|---|
| 车道车速与车距要求 | 产线节拍与定位工装 | 都决定采集窗口是否稳定，速度一变系统就要重调 |
| 门架摄像头拍车牌 | 工业相机拍产品表面 | 都是标准化点位上的机器采集，不是随手拍一张 |
| ETC 识别置信度 | 缺陷检测置信度 + 尺寸测量 | 都不是「非黑即白」，需要阈值分层 |
| 绿通 / 超限规则表 | 工艺标准与客户允收规则 | 把业务政策翻译成可执行判定条件 |
| 自动放行 | 自动 OK 装箱 | 大多数对象低成本通过 |
| 黄灯进人工岗亭 | 灰区进复判台 | 把有限人工集中在不确定样本上 |
| 拦截后倒车 / 引导处理 | NG 品剔出、返修或报废 | 判定结果必须驱动物理动作与追溯 |
| 新牌照样式上线 | 新膜材 / 新工装导入 | 都会引发识别域变化，需要回归验证 |
| 通行费争议与退费 | 客户退货、索赔与批次召回 | 漏判的代价在下游才完整兑现 |

# 5. 类比边界与系统要点

## A. 系统核心要点总结

- **数据输入要求与格式规范**：必须定义工位、光源角度、曝光、分辨率、产品位姿和物料批次；图像要与工单号、产线、班次、相机/模型版本绑定，支持从客户退货样本反查到具体检测记录。
- **AI 模型的能力边界与置信度**：模型擅长在稳定光学条件下找疑似缺陷，不等于理解「装机后是否影响用户体验」；置信度需与几何测量、分区规则联合使用，不能单独作为放行依据。
- **人工介入的触发条件与流程**：灰区样本、改判 OK 的 NG、高价值客户批次、新物料试产阶段应触发复判或双人确认；复判操作要结构化留痕并回流训练与标准修订。
- **系统的容错与降级机制**：相机故障、光源衰减、模型服务异常时，应停线或转全检模式，不能默认 OK；新物料可先走加强抽检策略，待回归通过再恢复自动放行。
- **成本结构**：包含工业相机与光源折旧、边缘算力、算法迭代、复判人力、停线损失、客户索赔与品牌损失；漏检一次的成本往往远高于多拦一次。
- **持续迭代与变更管理**：物料、工艺、客户标准变化都会导致模型漂移；需维护版本路由、金标样块库、分层 ppm 监控和变更回归门禁。

## B. 类比在哪里会失效

1. **ETC 误判多半是多收/少收通行费，工业漏检可能触发批量召回。** 收费站错误可在事后补扣；一块屏的 A 区划痕可能在客户端放大成「品牌质量崩盘」，代价不对称，不能套用「事后纠正」心态。
2. **车辆牌照规则全国相对统一，制造业客户标准千差万别。** 同一道 0.3 毫米划痕，A 客户拒收、B 客户可收；阈值不能全局一套，要按客户合同和分区映射。
3. **收费站车流是离散单件，产线是连续节拍系统。** 多 0.1 秒检测不只是慢一点，会传导成整线产能下降、在制品堆积和设备联锁停线——产品方案必须做产能仿真，不能只在实验室看指标。
4. **ETC 图像大多标准正面，工业表面有强反光、曲面、透明材质。** 光学方案往往比换模型更先解决问题；伪缺陷（膜纹、灰尘、水珠）占比高时，应先治环境再怪算法。
5. **AI 输出是概率性的，且随物料批次波动。** 今天 98.7% 不代表新膜材上线后仍成立；没有变更回归和在线监控，类比会让人误以为「装一次就永久省心」。

# 6. 深度业务洞察

1. **业务侧：客户要的是「零漏检」，合同写的却是「允收标准」。** 销售常把「AI 全检」当成卖点，但客户真正验收的是附件里的缺陷分区表。立项第一天就要把合同条款翻译成缺陷代码、测量方法和抽样方案，否则算法训练目标和商务承诺会永久错位。

2. **技术侧：实验室高分不代表产线好用。** 训练集常过度干净，产线却有振动模糊、油污、静电吸附灰尘；只做离线 mAP 会在上线首周被打脸。产品应推动「产线同源数据」进训练，并把伪缺陷样本单独建库，否则模型只会越来越会「误拦正常纹理」。

3. **运营侧：复判员是最贵也最容易被忽视的一环。** 没有证据包、相似案例和标准图示，复判会变成「凭感觉放行」；疲劳班次一致性下降，漏检和误拦会在人这一层重新出现。要为复判设计 ergonomics（人机工学）、轮岗、金标考核和双人复核，而不是只堆算法指标。

4. **合规侧：汽车行业、医疗器件等行业要求完整追溯链。** 需记录谁、在何时、用哪版模型、依据哪条标准判了 OK/NG；客户审计时拿不出追溯，比单次漏检更严重。涉及出境或客户现场部署时，还要确认图像是否含敏感工艺信息、存储期限和访问权限。

5. **商业侧：卖视觉质检不是卖摄像头，是卖「漏检代价可控」。** ROI 要同时计入停线成本、复判人力、返修报废和客户索赔；只讲「替代 6 个全检工人」会在误拦上升时被现场否决。定价可按工位数、缺陷类型数、变更频率和 SLA 分层，别用单一 SaaS 座位价硬套制造业。

# 7. 学习资料参考

## 官方文档 / API 参考

1. [海康机器人：机器视觉工业应用产品手册（中文）](https://www.hikrobotics.com/cn/machinevision)
   适合第一次进车间写视觉方案的 PM。重点看工业相机、光源、镜头选型与触发同步，理解「检测算法」之前还有一整套光学与采集约束。

2. [Basler 工业相机文档（中英）](https://docs.baslerweb.com/)
   适合要跟硬件工程师对齐接口的 PM。浏览图像采集、触发模式、像素格式和带宽章节，建立「为什么产线要固定 0.8 秒」的设备侧认知。

3. [ONNX Runtime 部署文档](https://onnxruntime.ai/docs/)
   适合关心「模型怎么上到边缘工控机」的 PM。了解推理延迟、批大小和硬件加速选项，便于在方案评审里讨论节拍是否吃得消。

## 行业最佳实践

4. [华为制造领域工业视觉质检实践（公开技术分享检索入口）](https://www.huawei.com/cn/huaweitech/publication)
   适合想看大厂如何把视觉质检纳入 MES 的 PM。搜索「工业视觉」「机器视觉质检」相关白皮书与案例，关注灰度上线、人机协同和变更回归流程，而非只看检测精度数字。

5. [Landing AI：视觉检测平台产品说明（英文，偏产品化视觉 AI）](https://landing.ai/)
   适合对比「传统机器视觉」与「深度学习缺陷检测」产品形态的 PM。用它理解样本标注、少样本启动、产线部署控制台等商业化模块，帮助写 PoC 到量产的里程碑。

## 适合 PM 的科普文章 / 课程

6. [吴恩达《Machine Learning Yearning》中关于误差分析与上线监控的章节（免费英文，可配合中文笔记）](https://github.com/chrisachon/Andrew-Ng-Machine-Learning-Yearning-Chinese-Translation)
   适合想建立「分层评估、先找最大错误桶」思维的 PM。工业质检同样要先问：哪类缺陷漏检最致命、哪类误拦最耗产线，而不是平均用力。

## 30 分钟动手小练习

7. **画一张「划痕缺陷裁决表」**
   假设你是手机屏外观质检 PM，列 3 个区域（A 用户可视区 / B 边框内侧 / C 结构区），4 类缺陷（划痕、污点、崩边、异物），为每格写清：自动 OK 条件、自动 NG 条件、是否进灰区、复判时限、NG 后物理流向。再额外回答：新膜材导入时哪几格规则必须重新签字？客户索赔样本回流后改阈值还是改模型？完成这张表，你就能在评审会上把「调高灵敏度」和「产线停不停」说清楚。
